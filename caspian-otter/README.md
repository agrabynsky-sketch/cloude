# Caspian Otter Adventure

A mini HTML5 game about the Caspian (Caucasian) otter, *Lutra lutra meridionalis*, for a school presentation.

- `index.html`: the standalone game. Open it in Safari on iPad or in any browser.
- `game.html`: the same game without the outer `<html>`/`<head>` wrapper (source for the hosted version).

Swim with your finger, catch fish, collect the 10 golden fact bubbles, then take the quiz.
There is also a Fact Book for showing the facts during the presentation, an EN/RU switch and read-aloud for every fact.
